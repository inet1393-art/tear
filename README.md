# یادآور کارها و اقساط (Android - Kotlin)

یک اپلیکیشن اندرویدی برای مدیریت کارهای روزانه و اقساط وام، با یادآوری تمام‌صفحه (شبیه آلارم ساعت) حتی وقتی گوشی قفل است.

## امکانات
- ثبت، ویرایش و حذف کارها با تاریخ و ساعت یادآوری
- ثبت وام با نام، وام‌دهنده، مبلغ کل، تعداد اقساط، مبلغ هر قسط، نرخ سود و یادداشت
- تولید خودکار جدول اقساط ماهانه از تاریخ شروع وام
- علامت‌گذاری هر قسط به‌عنوان پرداخت‌شده
- یادآوری‌ها به‌صورت **تمام‌صفحه** نمایش داده می‌شوند (مثل آلارم)، حتی روی صفحه قفل، همراه با صدا و لرزش، و دو دکمه «متوجه شدم» و «۱۰ دقیقه بعد»
- زمان‌بندی مجدد خودکار یادآورها بعد از روشن شدن گوشی (Boot)

## ساختار پروژه
```
ReminderApp/
  app/
    src/main/java/com/reminder/app/
      data/        -> Entity ها، DAO ها و دیتابیس Room
      adapter/      -> Adapter های RecyclerView
      alarm/        -> زمان‌بندی هشدار، BroadcastReceiver و صفحه تمام‌صفحه هشدار
      ui/           -> Fragment های کارها و اقساط
      MainActivity / AddTaskActivity / AddLoanActivity / LoanDetailActivity
    src/main/res/    -> layout ها، آیکون‌ها و رشته‌ها
```

## چطور باز کنم و APK بگیرم؟

### پیش‌نیاز
- Android Studio (نسخه Jellyfish 2023.3.1 یا جدیدتر پیشنهاد می‌شود)
- JDK 17 (معمولاً همراه Android Studio نصب است)

### مراحل
1. Android Studio را باز کنید و از منو: **File > Open** را بزنید و پوشه `ReminderApp` را انتخاب کنید.
2. اگر Android Studio پیشنهاد داد "Gradle wrapper" ایجاد شود (چون این پروژه فایل‌های wrapper را همراه ندارد)، گزینه تایید/ایجاد خودکار را بزنید. در غیر این صورت از منوی File > Sync Project with Gradle Files استفاده کنید.
3. صبر کنید Gradle Sync تمام شود (اولین بار به دانلود وابستگی‌ها از اینترنت نیاز دارد).
4. برای تست: یک گوشی را با USB وصل کنید (حالت Developer + USB Debugging فعال) یا یک شبیه‌ساز (Emulator) بسازید، سپس دکمه **Run ▶** را بزنید.
5. برای گرفتن APK تست (بدون امضا):
   - از منو: **Build > Build Bundle(s) / APK(s) > Build APK(s)**
   - فایل خروجی در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.
6. برای گرفتن APK نهایی و امضاشده (برای انتشار):
   - از منو: **Build > Generate Signed Bundle / APK**
   - گزینه APK را انتخاب کنید، یک keystore جدید بسازید یا از قبلی استفاده کنید و مراحل را طی کنید.

## ساخت خودکار APK با گیت‌هاب (بدون نیاز به Android Studio)

این پروژه یک فایل `.github/workflows/build-apk.yml` همراه دارد که با استفاده از **GitHub Actions** به‌صورت خودکار پروژه را می‌سازد و فایل APK را تولید می‌کند.

### مراحل
1. یک مخزن (repository) جدید و خالی در گیت‌هاب بسازید (public یا private، فرقی نمی‌کند).
2. کل پوشه `ReminderApp` را در آن مخزن آپلود کنید. دو روش دارید:
   - **روش ساده (بدون نیاز به خط فرمان):** در صفحه مخزن روی گیت‌هاب، گزینه "Add file > Upload files" را بزنید و کل محتوای پوشه `ReminderApp` (نه خودِ پوشه، بلکه فایل‌ها و زیرپوشه‌های داخلش) را بکشید و رها کنید (Drag & Drop). مرورگرهای Chrome و Edge ساختار پوشه‌ها را هم حفظ می‌کنند.
   - **روش خط فرمان (Git):**
     ```
     cd ReminderApp
     git init
     git add .
     git commit -m "Initial commit"
     git branch -M main
     git remote add origin https://github.com/USERNAME/REPO_NAME.git
     git push -u origin main
     ```
3. به تب **Actions** در صفحه مخزن گیت‌هاب بروید. یک اجرای (workflow run) به نام "Build APK" به‌صورت خودکار شروع می‌شود (چون فایل workflow با push روی شاخه main فعال می‌شود).
4. چند دقیقه صبر کنید تا اجرا کامل شود (آیکون سبز ✅ یعنی موفق بود).
5. روی همان اجرا کلیک کنید؛ پایین صفحه بخش **Artifacts** را ببینید و فایل `reminder-app-debug-apk` را دانلود کنید. داخل آن فایل zip، همان `app-debug.apk` قرار دارد که می‌توانید مستقیماً روی گوشی اندرویدی نصب کنید (باید از تنظیمات گوشی، نصب از منابع ناشناس را برای آن فایل مجاز کنید).

> نکته: این APK از نوع «debug» و بدون امضای رسمی است؛ برای تست و استفاده شخصی کاملاً کافی است. اگر بعداً خواستید نسخه امضاشده (release) برای انتشار در بازار اپلیکیشن بسازید، باید یک keystore بسازید و مراحل امضا را هم به workflow اضافه کنیم — اگر لازم شد بگویید تا آن را هم برایتان تنظیم کنم.

## مجوزهایی که باید هنگام اولین اجرا تایید شوند
- **نوتیفیکیشن (Android 13 به بالا):** برای نمایش یادآور لازم است.
- **زمان‌بندی دقیق هشدار (Android 12 به بالا - Schedule exact alarms):** برنامه به‌صورت خودکار صفحه تنظیمات مربوطه را باز می‌کند؛ لطفاً اجازه را فعال کنید.

## نکته مهم برای اطمینان از نمایش به‌موقع یادآورها
در برخی گوشی‌ها (به‌خصوص شیائومی، هواوی، سامسونگ و برخی گوشی‌های چینی) سیستم به‌طور پیش‌فرض اپ‌ها را در حالت خواب/بهینه‌سازی باتری محدود می‌کند. برای اطمینان از نمایش هشدارها به‌موقع:
- در تنظیمات گوشی، بخش «باتری» یا «Battery» بروید و «بهینه‌سازی باتری» (Battery Optimization) را برای این اپ غیرفعال کنید (Don't optimize / Unrestricted).
- در برخی گوشی‌ها باید اجازه «اجرا در پس‌زمینه» (Autostart / Auto-launch) را هم فعال کنید.

## محدودیت‌های فعلی و پیشنهاد برای توسعه بعدی
- تاریخ‌ها با تقویم میلادی محاسبه و صرفاً با اعداد فارسی نمایش داده می‌شوند (نه تقویم شمسی واقعی). برای تقویم شمسی دقیق می‌توانید کتابخانه‌ای مثل `persian-calendar` را اضافه کرده و منطق تبدیل تاریخ را در `AddTaskActivity` و `AddLoanActivity` جایگزین کنید.
- امکان ویرایش یک قسط به‌صورت مجزا (تغییر تاریخ یا مبلغ یک قسط خاص) هنوز اضافه نشده.
- بک‌آپ‌گیری و بازیابی اطلاعات (Export/Import) در نسخه فعلی وجود ندارد.
- برای شخصی‌سازی ظاهر (رنگ، لوگو)، فایل‌های `res/values/colors.xml`، `res/values/themes.xml` و `res/drawable/ic_launcher.xml` را ویرایش کنید.
